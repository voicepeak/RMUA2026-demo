# 角速度恢复配比与分级实测（2026-10-20）

保持 2.5rad/s、0.35rad 倾角、0.8m 位移、3s 超时硬边界。`standard` 是既有默认配比：姿态增益 1 倍、角速度阻尼 2 倍；`fast` 是显式实验候选：姿态增益 4 倍、阻尼 3 倍。比赛入口仍未启用控制，不因模型结果提升允许角速度。

## 先筛选模型候选

诊断工具 `python3 -m tools.diagnostics.recovery_gain_sweep --output runs/<unique-name>.json` 保留互不覆盖的结果及输入源文件摘要。模型假设：4.2rad/s 瞬间角速度冲击、固定恢复目标、80Hz 控制、电机一阶滞后 20/40ms、完整观测延迟 0/20ms（包含冲击前零角速度历史）、惯量 ±20%，滚转/俯仰/偏航/滚俯耦合四方向。

| 姿态/阻尼倍数 | 4s 末满足静定条件 | 倾角或位移越界 |
|---|---:|---:|
| 1 / 2 | 18/32 | 14/32 |
| 4 / 2 | 29/32 | 3/32 |
| 4 / 3 | 32/32 | 0/32 |
| 6 / 3 | 29/32 | 0/32 |

该筛选假定已经选中恢复目标，不经过实际安全状态机；4.2rad/s 超出现有硬边界。它不包含 ESKF、GPS 噪声、桥接存活期故障、接触或已验证的电机消费时延，不能作为 4.2rad/s 实飞能力。4/3 候选的最大倾角约 0.340rad，靠近 0.35rad 边界，不能用其零越界样本推断普适余量。

另用真实生产控制器和安全状态机验证 2.3rad/s 下的 24 个延迟/滞后/惯量偏差组合，以及原先 1.8/2.3rad/s 三轴六个标称组合。模型均通过；默认配比的标称回归保留，实验配比须显式选择。

## 实测失败必须保留

原模拟器和插件不改动、未加载原生诊断库；控制只读 initial_pose/IMU/GPS，独立线上指令与真值评测隔离。0.5→0.8Nm 是一次控制发布周期的附加俯仰力矩，而不是持续外力；正式混控 PWM 上限仍是 0.6。分级协议在任一场控制、审计或源码检查失败后停止，不继续更高激励。

- v2 首场未做静止初始化，起飞阶段先触发恢复并保持；计划脉冲没有发出，报 ANGULAR_EXCITATION_NOT_SENT，不能算脉冲试验成功。该场另有指令漏录。
- v3 加入早先成功脉冲试验已有的静止初始化。首场按计划发出一次 0.5Nm 脉冲，随后触发 ANGULAR_RECOVERY_HARD_BOUND；原始俯仰角速度约 2.862rad/s，线上序列审计通过。故障前记录 PWM 的暂定模型与运动出现大幅不一致，但消费时延/电机模型未认证，不能把它直接归因于桥接或该增益配比。
- 两个批次均只运行首场即按协议停止。2030/2041 的其余计划与全部 0.8Nm 场次均未执行；两次失败均保留在统计与证据中。

上述实测源码当时直接使用 4/3 配比；运行清单尚无 profile 标签。源码归档是权威版本。当前 v2/v3 配置显式写明 fast，便于用现在的分支选择相同配比，不以当前提交替代历史快照。

## 默认策略的兼容复核

新配比没有成为默认策略。单独以 standard、静止初始化、seed2030 运行 14s，真实发出一次 0.5Nm 脉冲；原始角速度峰值约 1.174rad/s，约 0.459s 后进入 RECOVERY_HOLD。恢复触发至保持后 0.5s 的独立姿态倾角峰值约 0.0934rad；960 条指令线上核对全部匹配。它只证明本次开发场次完成，不证明标准配比能恢复更大或所有自然冲击。

宿主 75 项单元测试通过；Noetic 72 项通过，3 项依赖 Git 的宿主快照测试跳过。两批失败及标准复核的五份源码归档全部独立逐文件重算 SHA256；原模拟器、规则设置与插件摘要一致。具体目录、模型结果、失败与复核数据见 docs/evidence/p1_recovery_gain_study.json。

P1 仍未验收。下一步需缩小指令交接/电机响应与 IMU 动力学不一致的时间窗，补足输入消费和时延证据，再验证控制能力；持续 IMU 失联策略及制动包络也尚未完成。
