# 验证矩阵

| 层级 | 当前验证 | 后续退出条件 |
|---|---|---|
| 单元 | 数据不可变、NaN、有效期、epoch、UNKNOWN、制动上界、发布者互斥 | 每次核心算法修改后运行 |
| 集成 | 容器中读取本地模拟器正式候选输入，记录类型、频率、缺失项 | 补齐消息与标定，核验正式服务器权限 |
| HIL/仿真 | PWM 电机脉冲、悬停、阶跃、独立 VEL 对照，隔离真值误差评测 | 传感器失联、延迟、饱和恢复、实测制动、冻结批测 |
| 比赛 | 待实施 | 冻结 train/validation/held-out 种子，多种子正式结果 |

测试种子不能以目录名假装已固定。本次 P0 审计所用种子须标记为开发观测，不能进入独立留出验收集。
