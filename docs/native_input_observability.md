# 原生 PWM 入口快照（迭代 27）

2026-10-23 整理；两场探索实际运行于 2026-10-20。先复核官方要求：100Hz 上限、单场模式锁、原碰撞/超时设置和算法输入隔离继续生效。[官方 README](https://github.com/RoboMaster/IntelligentUAVChampionshipSimulator/blob/RMUA2026-01/README.md) 于 2026-10-23 重新读取，仍列出 12.0.0.5。本轮未改原模拟器文件，不构成比赛验收。

新增显式 native-input 编译变体，在原 Init ABI 中仅替换回调入口，其余十个参数和原回调参数/结果透传。只有线程局部桥接记录已识别的 PWM Command 才采样；未知命令或传感器回调直接转发。通过只读 /proc/self/mem 有界采集参数存储的 16 字节，以十六进制保存，避免直接解引用可能已释放的存储。内核读取成功不证明对象仍存活，采样也不保证与并发写原子一致。

入口快照与发送日志四个 float64 转 float32 后逐字节比较；匹配候选必须已开始发布。相同值重复发布时取最近候选，因此不能据此唯一识别消费序号或认证传输上界。原回调开始和结束单独计时；返回后另采样，均不改变原函数调用次数。它观察的是入口附近的存储，尚未观察执行器消费或施加。

两场均没有入口读取失败、缺失返回或记录写入错误。第一场在稳定评测窗口前退出，不能报告稳定跟踪精度；第二场真实位置跟踪 RMSE 约 (0.0935,0.0314,0.0323)m，最大范数 0.3044m。两场探针版本不同，不构成冻结可靠性对照，也不证明物理冲击修复。

第一场 span860 的同一参数地址 0x713a7ab11f90，在入口采样之后、原回调返回之前发生释放，约早于故障 IMU 到达 20ms。原型缺少原回调实际起始计时，不能排除释放发生在采样日志与原调用之间，故不将其报告为“原回调执行期间释放”。修订版精确原回调区间内观察到的释放为零，不能从单场零事件排除竞争。

发送器增加发布开始/结束的绝对单调时刻，独立 IMU 评测增加到达时刻。区间计算为 [采样开始−发布结束, 采样结束−发布开始]；异步发送可能在 publish 返回前到达，负下界有效。第二场控制窗口内 2799 条入口，最小下界约 −1.98ms、最大上界约 32.89ms；另 326 条退出后的入口不进入延迟汇总。第一场没有控制结束绝对时刻，以末次发布结束作保守截断，202 条窗口内入口的最大上界约 21.87ms。

原型审计曾把退出后持有末条指令的尾部也汇入延迟，得到约 1.59s；该解释撤回。原始审计保留，重算文件另存 native_input_audit_iteration27_reanalysis.json，并记录新分析器 SHA256。不同版本的精确计时能力不能由重算补造。

两份归档各 220 文件已独立逐文件重算，均与各自 manifest 一致；运行前后源码及原环境摘要一致。机器可读摘要、原始文件哈希和本地目录见 docs/evidence/p0_native_input.json。宿主 79 项单元测试通过；Noetic 76 项通过、3 项宿主 Git 测试跳过；三项原生集成测试通过。自有 mock 覆盖十参数透传、原回调结果、不可读地址和回调期间受控释放，未读取已释放对象。

入口匹配将观测链推进到原生回调边界；入口之后的实际读取、存储复用、执行器应用及冲击因果仍未证明。P1 未验收，诊断库不进入部署镜像，competition runtime_control_enabled 仍为 false。
