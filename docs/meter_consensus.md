# 表盘候选多帧复核（迭代 65）

新增有界只读复核器：在同一 epoch、同一图像来源与候选设备轨迹上，至少三个不同时间戳的有效帧均给出三个红灯及同一表盘整数，才输出诊断性 `CONSENSUS`。帧需在其原始租约及墙钟时效内被接收；历史帧仅在有限窗口内参与一致性判断，最新帧过期后不再输出结果。重复/倒序帧不能续期；设备轨迹、读数或图像源变化以及任何灯状态不确定均中断累计。epoch 变更必须清空。

轨迹 ID、灯色和表盘候选目前均未经过真实工厂检测验证，相同轨迹也不等于已验证设备身份；诊断一致永远不授予上报资格，且不证明 20 个设备已检查完毕。没有调用上报服务。两环境各 3 项合成专项验证重复帧、目标/读数/灯状态变化、过期及跨 epoch 行为；实际识别、唯一性、误报率和官方业务响应仍待验证。
