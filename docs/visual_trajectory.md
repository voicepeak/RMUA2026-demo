# 局部视觉轨迹（迭代 61）

将已有双目相对运动在初始机体坐标系中连续组合，包含姿态对平移的旋转；对时间不连续、跨 epoch、非有限值和非法旋转拒绝并锁存断链。相对估计失败后只能开启新的局部段，不能跨缺失画面假定零运动。输出明确没有标定协方差及控制资格，不是 VIO 或全局位置。

复用一场历史低速 PWM 飞行的正式双目图像与名义相机配置，先生成相对运动、再保存局部轨迹，最后由独立评测读取真值，以各段起点真实姿态对齐，计算段内平移误差。26 次有效相对估计、1 次拒绝，形成 1 步和 25 步两段；较长段约 11.92s，末端误差约 0.048m。起点姿态只在事后评测中使用，不进入轨迹生成；结果不是无 GPS 长时漂移、动态场景准确率或在线性能保证。输入/输出摘要、断链原因与逐帧对照见 [证据](evidence/p2_visual_trajectory.json)。

单场开发数据与既有离线估计算法、名义标定均有局限；当前在线视觉链仍存在超时，尚未融合 IMU 或量化相关性/时延，不能用于控制。LiDAR 稀疏射线也尚不足以证明完整体素 FREE；逐点运动补偿、检测覆盖和外参仍待验证。
