# 双目门边候选（迭代 51）

2026-10-27。新增一个可运行的单帧候选生成器：从合法前视彩色图像提取近竖直红橙色边缘，排除贴边裁切的片段；从同一双目对的 SGBM 诊断视差中选取各边附近有效纹理区域，以视差支持数、一致性、边缘位置关系和名义双目三角化生成机体 FRD 坐标中的候选中心及估计宽高。严格保持原图像 stamp、epoch 和 lease；不兼容、过期、跨图像对的深度输入直接拒绝。

这是启发式 **候选**：红橙色车辆、线条或多个门之间可能错误配对；深度区域中值也不代表边框角点或无障碍开口。单帧输出明确标记未验证孔径、未标定米制几何、无控制资格，不报告过门，也不将门内空间标为 FREE。尚无多帧跟踪、门平面姿态、遮挡消歧或扫掠安全验证。

复用两场历史飞行的原始前视左右 PNG 与官方设置；按头时间差≤5ms一对一配对，并每五帧抽一帧。PWM 记录中 7 帧抽样：4 帧各生成 1 个候选、2 帧无候选、1 帧左右图不匹配；VEL 记录中 5 帧均各生成 1 个候选。没有门真值或人工逐帧标注，数量不能解释为检出率或几何准确率。两场包含的传感器和轨迹已在迭代 46 记录；逐帧边缘、视差、来源哈希和失败见 [证据](evidence/p3_stereo_gate_candidates.json)。

SGBM 加候选处理在宿主离线中位约 0.34s / 0.29s，超过 200ms 图像寿命。回放只在**图像采集时刻**调用候选函数，以核查几何链路；计算完成时结果已超期，不能作为在线输出。没有发送控制或调用官方业务接口。

单元检查覆盖已知矩形候选、贴边裁切、缺深度、两侧深度不一致、空背景、过期和跨 epoch/图像对拒绝；宿主 214 项通过，Noetic 211 项通过、3 项跳过。尚需对相机曝光/外参标定、实际门真值与车辆误报集、多帧世界跟踪和可通行净空、实时化与飞行闭环进行验证。
