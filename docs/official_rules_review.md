# 官方原件核对（2026-10-19）

从[官方规则中心](https://bbs.robomaster.com/wiki/20204847/809873?source=7)取得比赛规则 V1.0.0（2026-01-30，15 页）与参赛手册 V1.0.0（2026-01-15，18 页），逐项读取并检查起点和 LiDAR FOV 图。PDF 长度和 MD5 与官方附件元数据一致，URL、SHA256 及机器可读约束保存在 configs/official_rules_baseline.json；不在 Git 中重新分发全文。

| 原件位置 | 约束及工程影响 |
|---|---|
| 规则 p6–7 | NED、六段连续任务、门序与每段起点 30s 离开；任务推进必须依靠可确认事件 |
| 规则 p7 | 六段限时 180/180/180/200/220/200s；不能用慢速演示替代比赛验收 |
| 规则 p8 | 碰撞失败、力场累计超过 2s 失败、到达 8 后室外有持续风；实验不关闭碰撞或超时 |
| 规则 p9 | 后三段工厂不可跳过；GPS=0、20 设备中唯一三红灯、整数 0–50，错误上报失败 |
| 规则 p10–11 | 前后双目、30m LiDAR、IMU/GPS/风速计；风速计是规则列明的世界系测量，正式话题可达性仍单独核验 |
| 规则 p11 | PWM/VEL 由本场首次信号选定、最大 100Hz；不同模式必须不同场次 |
| 规则 p12 | 镜像 <15G、部署后 30s 离开起点、无 GUI、不得主动结束；有界实验不作为比赛入口 |

原件与设计的核心工程约束一致。接口细节继续以官方模拟器 README、实际 ROS 类型/MD5 及版本审计为准：规则 p9 对上报的概括写法不能替代 meter_report 的服务定义；IMU orientation 的本机可用性观测也不等于已完成其噪声和版本标定。

目前尚未通过 P1：保留一次未解释角速度突增；未认证普适制动下界，也没有完成赛程任务、工厂与正式分数验收。独立开发镜像默认只读、无 GUI、持续等待，不能用其小体积和启动成功冒充 30s 出发能力。
