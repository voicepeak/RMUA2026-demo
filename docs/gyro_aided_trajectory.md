# 陀螺辅助局部视觉轨迹（迭代 63）

将正式双目相对平移与正式 IMU 角速度积分结合：每次使用陀螺积分替代相对视觉旋转，来传播初始机体系下的姿态并旋转后续平移。两种输入按时间严格配对；视觉失败、陀螺缺括号或间隙过大均断开局部轨迹，不跨间断补造运动。估计过程不读 GPS、调试话题或真值；评测只在生成轨迹之后独立读取真值。

同一场历史低速飞行中，两种方法在相同 24 步、约 11.42s 区间使用同一视觉平移。纯视觉和陀螺辅助在对齐段起点后，末端位置误差分别约 0.04195m 和 0.04001m。其他两次视觉估计由于 IMU 未覆盖而拒绝，一次视觉估计本身拒绝。该单场差距很小，不能推断方法优劣；陀螺未做偏置校准，IMU 只是控制循环采样。逐帧结果和摘要见 [证据](evidence/p2_gyro_aided_trajectory.json)。

这是离线紧邻帧组合原型，不含加速度积分、误差状态更新、标定协方差或闭环重定位；尚未接入在线估计器、控制或工厂任务，不代表 VIO 和比赛验收。两环境新增专项测试验证 IMU 间断会断链；完整回归沿用上一轮 261 项。
