# 离线名义视觉惯性组合（迭代 68）

使用正式 IMU 姿态和比力在初始机体系传播位置、速度，利用双目相对位移做位置和速度残差的固定增益修正；输入只来自已保存正式双目与 IMU，结果写出后才以隔离真值评测。IMU 两端需有括号且间隙不超过 40ms，视觉失败或间断后断链。初始速度假定零，增益固定 0.5/0.3，没有偏置修正、协方差、相关性或迟到观测处理，输出无控制资格。

同一历史低速 PWM 场次的 24 步、11.42s 片段，姿态和比力辅助结果末端位置误差约 0.0728m；相同区间纯视觉约 0.0419m。该结果没有表现出改善，不能用作无 GPS 定位或控制，也无法从单场归因哪个假设导致误差。两次估计因 IMU 不覆盖而拒绝，另一次视觉估计失败；逐帧数据和输入摘要见 [证据](evidence/p2_inertial_visual_fusion.json)。

合成静止重力抵消和 IMU 间隙断链测试通过；宿主 271 项通过，Noetic 268 项通过、3 项跳过。需先标定传感器、估计初速和偏置、处理相关性及图像延迟，并跨场次验证，才可考虑在线融合与工厂 GPS 失效任务。
