# LiDAR 候选关联实验（迭代 57）

2026-10-27。第 56 轮发现体素包围盒中心在点跨过体素边界时会跳动；本轮增加可选点云质心，同时重新扩大包围盒以继续覆盖所有被聚类的占用体素。另增加可选的互为最近关联：候选和轨迹必须互为最近，且双方次优距离比最优至少大 0.5m，否则仍按歧义拒绝。默认仍是第 56 轮的包围盒中心与严格唯一关联，候选算法不授予控制资格。
