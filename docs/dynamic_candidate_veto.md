# 动态候选的连续轨迹拒绝（迭代 58）

2026-10-27。新增一个针对 LiDAR 动态候选的连续相交检查，并作为局部静态规划器的可选输入。每段轨迹在机体跟踪余量及连续加速度偏离界内扩展；候选障碍按估计速度推进，并根据调用方显式给出的初始位置误差、速度误差和加速度界膨胀。单次观测没有速度时使用另给的速度上界。检查闭合盒的整个区间，采样点之间的交叉和擦边均拒绝。

源轨迹、候选快照、每条轨迹须同 epoch 且当前有效；候选过期、预测超过最多 0.5s、计算预算不足或输入不合法时拒绝。启用动态候选检查后，输出参考 lease 还会受动态快照及各条候选原始有效期约束。测试同时覆盖静态空闲场景、交叉、接触、单次观测、过期、跨 epoch、预算及规划器实际拒绝路径。

`NO_DETECTED_DYNAMIC_CONFLICT_UNCERTIFIED` 仅表示在输入候选和所给假设下未发现相交。LiDAR 可能漏检、候选包围盒可能不完整、关联和运动界未标定；空候选也不证明安全。`DynamicCheck.safety_certified` 和 `LocalPlan.dynamic_coverage_certified` 始终为 false。未启用可选参数时既有静态规划行为不变；这条路径尚未接入比赛控制。
