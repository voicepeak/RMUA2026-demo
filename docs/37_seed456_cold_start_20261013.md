## 原因及证据

视觉模型加载和首帧推理期间，空门图控制器已经以2米/秒消耗30米侦察范围；视觉没有稳定后续门，触发既有HOLD。相机图中YOLO有候选，但深度兜底把门的物理宽/高都硬限制8米，第一阶段约12.8米宽的真实门被剔除。检测矩形角点也会参与四角三角化，错配角点可产出不可靠“实测”几何，阻断后面的深度兜底。

工作区`experiments/seed456_cold_start_20261013/`包含18的保存双目图离线探针。原8米尺寸筛选27帧中没有形成持续门轨迹；按宽18/高12米边界、框体稠密视差和多帧一致性处理，同一批图可积累27次支持和多个hard_anchor。JPEG记录与现场同步原始图不同，不能把离线探针当实飞通过。

## 修复d99f1fb

- 非123第一阶段新增`wait_for_first_map=true`：在起点起飞悬停，直到在线门缓存或经过原质量筛选的高度引导出现，再进入原导航。模型加载期间不消耗侦察距离；地图再次丢失时，原有限RECON→HOLD与ABORT仍生效。
- 非123视觉启用`cold_start_gate_map`：仅真实左右关键点走四角几何；纯检测框走门框像素深度与重复观测，不把矩形角点当门平面实测。
- 第一阶段/非车辆道路门尺寸上限宽18、高12米；车辆段保留8米。兜底遵循同一配置上限，完整两侧白柱/橙边筛选仍执行。
