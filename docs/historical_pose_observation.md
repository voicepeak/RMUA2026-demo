# 图像头时间与历史 ESKF 位姿（迭代 31，2026-10-23）

迭代 29 观察到图像头相对 IMU 落后约 150ms；不能直接把当前位姿用于该时刻图像的几何处理。本轮增加有界历史缓存及正式传感器只读验证，仍未标定曝光时刻/外参，也没有执行世界投影或深度融合。

PoseHistory 最多保留 1s/256 条不可变 15 状态 ESKF 快照，记录源回调进入时的 wall monotonic。查询要求当前源状态仍在有效期内、最近回调不超过 100ms、当前及两端历史状态健康、同 epoch、图像时间被已有状态覆盖；不外推。插值间隔不得超过 30ms，位置线性插值、姿态采用最短弧 SLERP，正确处理 q 与 −q 的等价性。

位置变化相对两端速度积分残差超过 0.1m，或姿态变化相对角速度积分残差超过 0.05rad 时拒绝插值。这些是局部估计跳变检查，不是经标定的运动或插值误差上界。两端原协方差对角保留，不编造插值后的可信协方差。

HistoricalPose 独立于当前 StateEstimate，没有新 valid_until，current_control_eligible=false、uncertainty_calibrated=false。过去状态的原有效期不被延长；查询还必须有新鲜当前状态。重复源样本不刷新 wall deadline，显式 epoch reset 清空所有旧数据。FlightSensors 的历史功能默认关闭，只读验证节点显式传入缓存；IMU 回退清空缓存并保持原有故障锁存，不自动在旧场次恢复控制。
