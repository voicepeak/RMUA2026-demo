# 安全证据边界

P0 只读审计不发布控制、不调用工厂上报。比赛 PWM 通路保持关闭，禁止把全零 PWM 当悬停。有界本地 PWM 辨识单独使用新场景，实验停止时由宿主关闭模拟器；这不是可移植到比赛的安全回退。

控制租约只能排除遵守该协议的进程，不能阻止外部任意 ROS 发布者。控制节点在发布前和运行中每 0.1s 检查 ROS 图；指令门拒绝过期、epoch 变化、序号重放、非法 PWM，按 wall monotonic 限频至不超过 100Hz。图查询本身尚未与发布线程隔离，不作为硬实时保证。

限频同时约束上次 publish 完成到下次发送的间隔，避免网络阻塞后的赶发。seed1008/1009/1010 的 GPS 归零/IMU 丢包/时钟回退验证均未出现小于 10ms 的完成间隔。IMU 过期和回退目前是锁存故障，本地宿主终止模拟器；这不等于自主飞行环境具备失联恢复。

已有离线检查覆盖：非法数值、有效期、重置 epoch、坐标系不一致、定位退化、PWM/VEL 发布者冲突、未知/过期体素和制动距离的数学约束。

尚未证明：电机混控方向、PWM 范围与推力映射、悬停与失联恢复、连续机体扫掠体积、动态障碍保守占据、道路/力场边界、实际制动下界和完整比赛成功。没有这些证据不得启用比赛配置。
