# 参考带内爬升瞬态放行（2026-10-08）

## 现象与证据

车辆段早期与中段出现"净空充足却全候选被拒"的间歇刹停：

- `legacy_visible_20261008_17` 车辆段 0–13m：多帧 `COMMAND_BLOCKED`，`path_clearance` 1.5–1.65m，`candidate_count` 60，`blocked_bounds_accepted=false`；s≈343 一帧路径 22.7m、净空 1.75m 仍 `COMMAND_BLOCKED`（120 候选），随后 `LIDAR_TRACK` 恢复。
- 冻结现场 `mission/leg_3_5/clouds/1791437451.983_s343.0.json(.npz)` 诊断：所有候选共享的停车垂直剖面在响应前缀内越过"参考 Z±1.25m"带上界，峰值 +0.277m（起点在带内 -0.407m，各情景尾段回到 -0.498m）。`_bound_ok(timed=True)` 对"起点在带内"只允许 1mm 瞬态，直接否定所有候选；而横向前进候选因此全部失效。

物理原因：实测垂直速度（NED -0.9m/s 爬升）在反应延迟+指令保持窗口内继续爬升，穿过带边界，属于测量惯性，任何指令都无法消除。

## 修改

`repo/ros_ws/src/route_follower/scripts/lidar_navigation.py`（运行副本已同步）：

1. 新增 `inside_transient_allowance(velocity,age)`：`min(0.6, 0.15 + |vz|*(reaction+age))`。
2. `_bound_ok` 增加可选 `inside_transient`：起点在带内时，允许峰值高于边界不超过该额度，且**每个情景尾段必须回到带内**；默认 0 保持原严格行为。
3. `_floor_ok` 的两个高度带检查传入 `self.inside_transient`；地面/出发地板检查不变。
4. `select` 按实测垂直速度与云龄计算 `self.inside_transient`。
5. 原始回波 `command_clearance` 仍为完整 1.25m 停车包络检查，未放宽。

对比补丁：`lidar_navigation.patch`（基线为 run18 运行快照）。

## 未解决：起飞段出发地面瞬态

run19 车辆段 s0–16m 仍有约 9 段短刹停。冻结帧诊断（`diag_frame.py` 输出）：

- `1791438737.481_s7.6`：26 个候选全部被**出发地面检查**拒绝，`path_z-floor_limit` 峰值 +0.027m；
- `1791438742.002_s9.2`：+0.033m；`1791438749.733_s13.0`：+0.055m；高度带与横向均在内。

即无人机在交接段低于出发地面界 3–6cm，而地面检查的定时瞬态仍为 1mm。该机制与 run13 记录的 0.4mm 漂移同源但幅度更大，涉及真实地面安全，**本次未放宽**。另一个遗留入口是停在缓冲外且无几何路径时的原地让行（run18 s≈806 刹停），也保持现状未改。

## 边界

- 这是经验参考带的瞬态放行，不是形式化安全证明；它不改变原始障碍 1.25m 停车包络检查。
- 冻结复放不是新飞行证据；单次实跑对比受车辆场景随机性影响，不能当作成绩或稳定性结论。

## 追加：停车包络基础裕度放行（2026-10-08 第二项）

现象（run19 车辆段 s549-554 窄缝）：路径净空 1.45m，但响应模型横向滞后使候选停车包络最低 1.155m，仅高出基础裕度 1.15 5mm，被 1.25 的路径+包络统一阈值全部拒绝，只能 0.5m/s 爬行或刹停。

修改：

- `execution_guard.command_clearance_components` 分离原始回波与动态预测最小距离。
- `_commands` 在 `lidar_envelope_margin`（>1 才启用）配置下，允许模拟停车包络对**原始回波**低至该基础裕度；**动态预测仍必须 ≥1.25m 路径缓冲**。路径搜索和缓存前缀仍要求 1.25m。
- 参数经 launch `lidar_envelope_margin`（默认 0=关闭）传入；比赛入口 `race_start_watch.py`/`race_runner.py` 显式设为 1.15。

验证：

- 冻结帧 s551.1：关闭时 `COMMAND_BLOCKED`，开启 1.15 后 `LIDAR_TRACK`（官方脚本目录直接复现）。
- 宿主/ROS 各 493 项通过（新增 1 项：包络裕度只对原始回波、动态预测保持缓冲、默认关闭）。
- 补丁：`envelope_margin.patch`（基线 run19 运行快照）。
- 实跑：`experiments/legacy_visible_20261008_20`。

边界：面向用户"可通行车缝仍减速"的定向放宽；模拟包络最低 1.15m、路径最低 1.25m。若事件审计要求所有样本 ≥1.25m，应关闭该参数（设 0）。

## 追加：起飞段出发地面瞬态（同日第三项）

现象（run19 车辆段 s0–16m，每轮固定损失）：所有候选被出发地面检查拒绝，`path_z-floor_limit` 峰值 +0.027~0.055m，超过原 1mm 定时瞬态；HUD 数据显示该段约 9–11 段短刹停（约 13s）。

修改（`lidar_navigation.py`）：

- `_bound_ok`：定时包络在"起点已越界"分支也接受有界瞬态（`max(0.001, inside_transient)`），仍要求每个情景尾段减少至少 1cm；"起点在界内"分支行为不变（需显式瞬态且尾段回界）。
- `_floor_ok` 的地面检查传入 `min(0.1, inside_transient)`；道路高度带仍用完整 `inside_transient`；原始回波检查不变。

验证：

- 冻结帧 run19 s7.6/s9.2/s13.0 由 `COMMAND_BLOCKED` 变 `LIDAR_TRACK`。
- 宿主/ROS 各 493 项通过。
- 实跑：`experiments/legacy_visible_20261008_23`。

## 追加：门间口袋卡死与应急撤退（同日第四项）

现象（run26 车辆段 s≈568，门与门之间）：路径搜索连续给出 0.5–4m 短桩后，飞机在缓冲内贴入密集表面（最近回波 0.292m，0.5m 内 1370 点），`COMMAND_BLOCKED` 持续 21s，垂直指令 ±2–3m/s 振荡后归零；监视器按无进度停止。

诊断：`_stationary_escape`/`guard.escape` 用三维速度门限 `<0.8`（当时垂直 2.45m/s 直接跳过），且"任何近点不得有靠近分量"的一票否决使"贴面"状态下 57 个方向全灭。

修改（`execution_guard.py`、`lidar_navigation.py`）：

- 原地脱困/恢复/条件恢复的"静止"判据改用水平速度（认证仍使用完整三维响应）。
- `escape` 移除与逐点分离检查重复的一阶靠近否决；保留每个回波不低于 `min(初始距离, 1.25m)` 的单调约束与完整响应认证。
- `filter_command` 无候选时：若最近回波 <0.6m 且 0.5m 内有 ≥16 个回波（贴面退化态），沿局部点云外法向以 ≤0.6m/s 应急撤退，标记 `EMERGENCY_RETREAT`；所有常规认证候选优先，不改变其行为。

验证：冻结帧 s567.9 由 `COMMAND_BLOCKED` 变为 `EMERGENCY_RETREAT`；宿主/ROS 各 493 项通过。实跑：`experiments/legacy_visible_20261008_27`。
