# 视觉相对旋转与陀螺一致性（迭代 62）

从已保存的正式双目图像估计读取相对旋转，从历史控制日志只提取正式 IMU 原始角速度及对应时间/epoch；陀螺按实际时间梯形积分，端点插值必须有前后括号，样本间隙大于 40ms、缺括号、非法旋转或跨 epoch 拒绝。该诊断没有陀螺偏置修正或标定的不确定度阈值，不修改定位或控制。日志中 IMU 是控制循环采样，不能当成全频记录。

一场历史低速 PWM 场次中，26 个视觉运动估计有 24 个获得完整陀螺覆盖，2 个缺少括号而拒绝；24 个旋转差中位约 0.00088rad，P90 约 0.00201rad，最大约 0.00280rad。这只是同一开发场次下两个观测的相符程度，没有真值参与诊断；不证明视觉平移准确、估计独立、偏置已标定或动态环境可靠。[逐对记录与摘要](evidence/p2_visual_gyro_consistency.json)。

宿主 261 项通过；Noetic 258 项通过、3 项跳过。单测包括已知角速率插值积分、缺括号/间断拒绝和非法旋转。视觉惯性融合、在线时效及工厂 GPS 失效定位仍未验收。
