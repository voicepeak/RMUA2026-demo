# SGBM 像素视差诊断基线（迭代 30，2026-10-23）

按设计 Sprint C 继续建立可测量的双目基线。查阅已安装 OpenCV 4.2.0 的接口说明及[官方 4.2.0 定义](https://github.com/opencv/opencv/blob/4.2.0/modules/calib3d/include/opencv2/calib3d.hpp)，使用原始正式相机输入；无新模拟器场次、控制发布、debug 或真值输入。曝光/外参/矫正尚未标定，因此仅计算像素视差，不换算米制深度。

SGBM 参数为 128 视差、5×5 窗口、单通道 P1/P2=8/32×窗口面积、uniqueness=10、speckle=100/2。分别计算左右方向，反向范围为 1−numDisparities 至 0；在左像素对应的右坐标处双线性采样反向视差，要求两邻点有效、正反差不超过 1px，并检查双侧局部纹理标准差至少 2。搜索边界、无纹理、遮挡和其他不一致像素为 NaN，单独保留不可变 valid 掩码，不补洞、不将未知当作 FREE。

输出保留原输入时间与有效期，不因耗时或历史重放而刷新；StereoPair 进一步约束两个图像的 frame/epoch、尺寸/编码、时间戳与最短有效期，禁止构造跨 epoch 或延长有效期的配对。输出为 front_left_image 像素坐标，原左/右测量时间分别保留；不做世界投影或规划净空推断。

合成随机纹理水平平移 8/16px 的内区有效比例均超过 90%，RMSE 小于 0.2px，具体数值见机器证据。纯色图像全部为未知，右图遮挡条带不生成有效视差，垂直错位 8px 的随机纹理内区有效比例低于 5%。这些是已知像素对应的算法检查，不是模拟器真实深度标定。
