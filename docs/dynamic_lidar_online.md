# 只读 LiDAR 动态候选链路（迭代 59）

订阅官方 LiDAR、IMU、GPS 和初始位姿，按扫描时间查询 ESKF 历史位姿，将端点变换到世界坐标，聚类、关联并对当前估计位置的 0.2 秒静止探针执行动态候选冲突检查。输入和输出均检查原始时间租约、墙钟时效及 epoch；异步输入采用容量 1 的最新帧槽。ROS 图审计和逐行时效审计仅验证诊断证据一致性。

两场 8 秒未插桩只读观测分别收到 77/78 帧，处理 31/27 帧，冲突 16/16 帧，未检测到候选冲突 15/11 帧；中位处理耗时约 28.4/35.4ms，最长约 51.1/47.1ms。第二场 51 帧在输入时不满足时间条件，全部为点云时间领先最新 IMU；第一场未记录被拒绝帧的具体时间，不能推断其原因。关联歧义累计 309/279 次，匹配仅 42/30 次。完整统计、哈希和清理结果见 [证据](evidence/p4_dynamic_lidar_online.json)。

该探针并非规划器的真实运动轨迹，检测对象也可能包含静态结构；点云没有完整逐点运动补偿，聚类、数据关联和动态边界尚未标定，检测覆盖率未知。未检测冲突不代表 FREE 或安全，输出不可用于控制或验收。P1/P2、在线穿门、实际动态避障和完整比赛均未验收。下一步应在不扩大时效预算的条件下等待 IMU 历史覆盖扫描时间，并继续解决关联歧义。
