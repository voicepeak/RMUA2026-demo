# 稀疏双目相对运动基线（迭代 45）

2026-10-27。新增 `perception.visual_odometry.stereo`，使用前一时刻左右图像的双向 ORB 匹配进行名义双目三角化，并匹配前后左图；对共同特征进行 PnP RANSAC，估计当前机体系相对前一机体系的旋转和平移。变换包含相机外参和相机与机体原点之间的杠杆臂。拒绝跨 epoch、非递增或过大时间间隔、超过 5ms 的双目头时间差、少量特征、几何退化、分布过窄及低内点率；保持明确的失败结果。

该实现只读合法图像与公开名义相机设置。结果没有控制资格，也没有与 ESKF 融合；没有真实相机米制标定、曝光同步、动态物体识别和运动模糊验收。它是向无 GPS 定位迈出的一步，不是 VIO 或工厂定位验收。两帧来源的有效期不被延长，没有将离线结果发布给控制器。

在两场既有只读采集的连续捕获中，各 5 对获得结果。图像相隔约 1.5–1.9 秒，主要为地面低运动数据；与同场 IMU/GPS ESKF 历史位姿比较，10 对平移差约 0.025–0.103m，旋转差约 0.014–0.054rad。ESKF 不是独立真值，这些差异不能作为精度或失败归因的证明。主机单线程回放多数计算约 0.12–0.13 秒，首对约 0.32 秒；Noetic 首场约 0.13–0.14 秒，均不含实时消息接收与其他争用，不能宣称 150ms 在线有效期通过。详细逐对结果见 [证据](evidence/p2_stereo_odometry.json)。
