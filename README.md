# RMUA：自主无人机备赛

本仓库以 2026 赛题和模拟器为开发参考，面向后续赛季备赛；后续赛季规则以官方最终发布为准。当前主线是**面向完整赛程建设以 PWM 为核心的自主飞行系统**，以逐层闭环和可复现实验验证进展，不依赖特定种子或调试真值。

## 现在做到哪里

- `main` 是重构工程：已有传感器接口、IMU/GPS 估计、有界 PWM/VEL 实验和感知规划原型；**尚未验收稳定 PWM 飞行、在线自主穿门或完整赛程**。默认开发镜像只读，不能作为参赛镜像。
- `beta` 是旧版对照：历史 seed 123 实验曾通过第一段并进入车辆段；后期也尝试从空地图适配其他种子，但没有通过跨种子第一段验收。历史实飞依赖条件与当前分支状态不可混同。
- 以下文档基于 2026-10-28 检查的源码快照和仓库记录；**历史飞行没有在本次文档整理中重跑**。
