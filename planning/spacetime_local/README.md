# 局部静态轨迹候选

`static_candidates.plan_static_local` 消费新鲜、健康的状态估计、当前参考 p/v/a、在线目标、
三态地图和显式模型限制，比较直达与相对目标方向左右偏移的候选。没有种子路径表。

每段为五次 Bezier 曲线，保留初始 p/v/a，在路点及目标收敛到零速度/加速度。对导数
控制多边形做固定深度细分，得到覆盖整个区间的速度/加速度上界，再检查整条停止参考的
连续扫掠空间。限制候选尝试数、采样段数和每条轨迹体素工作量，不能拿部分检查放行。

选择代价最小的已验证候选；未知/过期地图、状态或起始参考不匹配、运动上界超限时，
返回无候选及原因，不虚构悬停或发出 PWM。起始参考时间须等于查询时刻，不给旧/未来
参考重写时间。地图必须覆盖完整停止参考，不能只保证
输出短租约这段空间。输出租约不超过源状态有效期，`LocalPlan.reference_at` 拒绝
过期和其他 epoch 查询，源状态/地图元数据原样保留。

这些仅是静态地图和参考运动学条件。实际机体/跟踪包络、制动/推力、道路/力场、动态
对象及运行时 IMU/wall 时间健康仍需独立检查；当前没有接入飞行控制。合成已知 FREE
案例不代表真实传感器已经提供可信地图。

设计依据：11.1、11.3；阶段状态见 docs/implementation_status.md。
